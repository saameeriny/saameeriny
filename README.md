## Featured — SAR / GIS flood mapping

### M.S. thesis — Mapping Flood Extent Using Coordinate-Aware SAR Clipping and Machine Learning
- Sentinel-1 C-band RTC, Lake Travis / Colorado River Basin, Tropical Storm Barry
- Pre-flood: May 24, 2025 | Flood: July 11, 2025
- Pipeline: coordinate-aware, projection-aware clipping · median filter · log-ratio · 6-level stationary wavelet transform (SWT) · 2-component Gaussian mixture model (GMM) per scale · multiplicative product consensus
- Committee: Bogdan Gavrea (chair), Nilesh Dixit, Olaniyi Ajadi — approved April 2026, ASU May 2026
- Thesis poster (same work, poster-reported): Precision 0.88, Recall 0.77, F1 0.82
